# Chinnawan Sriprasong — Portfolio

Personal portfolio website built with **React, HTML, CSS** and **Framer Motion** (Apple-style scroll animations).
Bilingual (TH / EN) with dark & light themes.

## Run locally

```bash
npm install
npm start
```

Then open http://localhost:3000

## Project structure

```
public/index.html        page container
src/index.js             renders <App /> into index.html
src/App.js               top-level component (all sections)
src/index.css, App.css   global styles
src/components/          Hero, About, Skills, Projects, Experience, Contact, Navbar …
src/data/portfolio.js    all site content (TH / EN) — edit here
```
